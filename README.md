# PokeMatch

A classic **Pokémon tile matching game** with adorable icons, fun animations, and interactive gameplay. Test your memory and Pokémon knowledge with this lightweight browser-based game!

## 🕹️ Features

- 🧠 Memory-based tile matching  
- 🎨 Smooth CSS animations and transitions  
- 🐾 Cute Pokémon icons for added fun  
- 📚 Fun Pokémon facts displayed after each successful match  
- 💻 Responsive layout, playable on both desktop and mobile devices  

## 🚀 Live Demo

Play it here: [PokeMatch Demo](https://jeslyjames.github.io/PokemonTiles/)

## 🛠️ Built With

- **HTML5** – Structure of the game  
- **CSS3** – Styling and animations  
- **JavaScript** – Game logic and interactions  
- **jQuery** – DOM manipulation and event handling
